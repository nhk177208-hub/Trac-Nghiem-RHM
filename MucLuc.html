MucLuc.html — nhận diện mục lục (MỀM)

File này nằm cùng cấp với index.html. Mọi luật và mọi đoạn code lập mục lục chương sách đều nằm trong thẻ <script> ở cuối file này; index.html không còn chứa luật hay code lập mục lục nào, chỉ đọc file này (và Menu.html của từng sách) rồi gọi các hàm bên dưới. Sửa file → mở lại chương (hoặc bấm “🔄 Cập nhật mục lục”) là có hiệu lực, không cần sửa index.html.

1. Hai file, hai vai

FileVị tríVai trò
MucLuc.html (file này)cạnh index.htmlNhận diện mềm, dùng chung mọi sách: luật dò tiêu đề offline, prompt AI, code xử lý, cách đọc Menu.html.
Menu.htmltrong thư mục từng sáchNhận diện cứng, riêng sách đó: mục lục từng chương (sections), cách đọc PDF (cột, lề, vùng bỏ qua), và (nếu cần) ghi đè luật / code riêng cho sách.

Ưu tiên khi lập mục lục một chương: có sections trong Menu.html → dùng đúng danh sách đó (không dò, không gọi AI), trừ khi chương có ai_extend: true. Không có → dùng luật mềm trong file này (dò offline + AI).

2. Nạp sách mới cho AI nhận diện

Chỉ cần sửa 1 trong 2 file: luật chung → sửa RULES trong file này; riêng một sách → tạo/sửa Menu.html trong thư mục sách đó (mẫu: file Menu.html đi kèm).

3. Hướng dẫn cho AI lập Menu.html

  1. Mỗi chương là một khóa trong chapters, khóa là tên file PDF của chương (có hoặc không có .pdf; so khớp không phân biệt hoa thường/dấu câu). chapters cũng có thể là mảng {file, ...}.
  2. sections: mảng theo đúng thứ tự xuất hiện trong chương. Mỗi mục: src = tiêu đề nguyên văn tiếng Anh như in trong PDF (app tìm chuỗi này trong chữ của PDF), vi = tên tiếng Việt, lvl = cấp 1–10 (1 = mục lớn nhất), page (tùy chọn) = số trang của file PDF chương (bắt đầu từ 1) để chọn đúng chỗ khi tiêu đề lặp nhiều lần.
  3. Không lập mục từ hình, bảng, hộp chú thích, câu văn thường. Không bịa tiêu đề; nếu src không khớp chữ trong PDF, app báo “x/y mục không khớp”.
  4. Tùy chọn mỗi chương: mode: "soft" (bỏ qua sections, dùng luật mềm), ai_extend: true (nạp sections rồi vẫn cho AI quét thêm), intro: false (không tự thêm mục “Mở đầu”), offline_rules, ai_prompts, ai_hint (ghi đè riêng cho chương).
  5. Cách đọc PDF (app dùng, không phải code mục lục): layout {columns: [[x0,x1],…], zones: [{y0,y1,columns}], top, bottom, skip: [[x0,y0,x1,y1],…]} — tọa độ là tỉ lệ 0..1 của trang, y tính từ mép trên; page_layouts: [{pages: "odd" | "even" | "3-9" | số | mảng, …layout}].
  6. Cấp sách (ngoài chapters) cũng có thể có offline_rules, ai_prompts, ai_hint để ghi đè luật chung cho cả sách.

4. Luật mềm (RULES.offline_rules)

KhóaÝ nghĩa
min_length, max_lengthĐộ dài tối thiểu / tối đa (ký tự) của một tiêu đề.
heading_font_ratioCỡ chữ tiêu đề so với thân bài (khi sách không có chữ đậm).
gap_up_ratioKhoảng cách tới dòng trên (tính theo cỡ chữ) để coi là đầu mục.
flush_left_toleranceĐộ lệch tối đa so với lề trái cột.
allow_run_in, run_in_max_lengthCho phép tiêu đề đứng chung dòng với đoạn văn (chữ đậm đầu dòng kết thúc bằng dấu chấm).
start_regexTiêu đề phải bắt đầu bằng ký tự khớp regex này.
exclude_regex / include_regexLoại bỏ / ép nhận một dòng là tiêu đề (không phân biệt hoa thường).
skip_text_regexDòng khớp regex này bị bỏ khỏi chữ chương.
outline_box_label_regexNhãn của khung mục lục in sẵn trong trang (các dòng ngắn ngay dưới nhãn bị bỏ).
first_page_title_skipBỏ tiêu đề chương / tên tác giả ở trang 1.
merge_offline_candidatesSau khi AI quét, gộp thêm các tiêu đề dò offline mà AI bỏ sót.

5. Các hàm app sẽ gọi (viết trong script bên dưới)

HàmKhi nào
begin(H)Trước khi đọc chữ cả chương (xóa bộ nhớ đệm luật).
excludeItems(c)Mỗi trang: loại bớt các mảnh chữ không đưa vào chữ chương (c.excl.add(item)).
trimOrder(c)Mỗi trang: chỉnh danh sách chữ theo thứ tự đọc (trả về mảng mới).
detectCandidates(c)Mỗi trang: dò dòng nào là tiêu đề, trả về [{s, t, fh}].
hardSections(H)Mở chương: nạp mục lục cứng từ Menu.html.
detect(H, progress)Bấm “📑 Nhận diện / 🔄 Cập nhật mục lục”.
subSections(H, o)Bấm “🔁 Quét lại” một mục.

H là cầu nối do app đưa vào: H.text(), H.pages(), H.chapter(), H.menu(), H.chapterMenu(), H.menuSig(), H.ai(system, user, maxTokens), H.hasAi(), H.showGate(), H.toast(msg), H.glossary(text), H.glossRule(), H.fixVi(vi, src), H.lineStart(text, i), H.mergeSecs(a, b).

6. Ghi đè code riêng cho một sách

Trong Menu.html có thể gọi TOC.override({ detectCandidates(c) { … } }) để thay đúng hàm đó (và chỉ cho sách đó). Trong Menu.html, TOC.base là bộ hàm mặc định của file này nếu muốn gọi lại.
